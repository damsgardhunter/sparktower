# Growth loop: publish a path artifact

Something a builder finishes becomes the page the next stranger finds.

| Step | Where it lives | Proof |
| --- | --- | --- |
| Finish a path step → **Generate artifact** (a stored `path_artifacts` row made from the step's answer, build files or plan) | `server/artifact-routes.ts` (`generateArtifact`, `POST /api/projects/:id/path/tasks/:taskId/artifact`), `shared/path-artifacts.ts` (`artifactFromStep`), `shared/schema.ts` (`pathArtifacts`), `migrations/0008_path_artifacts.sql` | `test/integration/path-artifacts.test.ts`, `test/unit/path-artifacts.test.ts` |
| **Publish** with a public title, tags and a backlink to the project and its path; a feed post links to it | `POST /api/artifacts/:id/publish` (`validatePublish`, feed post `entityType: "path_artifact"`, `markStepsShared`), `client/src/components/continue-path-card.tsx` (`PublishArtifactDialog`), `client/src/components/path-panel.tsx` ("Publish as artifact"), `client/src/components/feed-post-card.tsx` (public page chip) | `e2e/growth-loop.spec.ts` |
| A **shareable, indexable URL**: `/a/:id`, readable with no account, with its own `<title>`, description, canonical and Open Graph tags in the HTML | `GET /api/public/artifacts/:id`, `artifactPageMeta` + `injectPageMeta` applied in `server/static.ts` and `server/vite.ts`, `client/src/pages/public-artifact.tsx`, `client/src/App.tsx` (public route) | `e2e/growth-loop.spec.ts` (og:title in the HTML, logged-out read) |
| **Found without the link**: `robots.txt` names the sitemap, `/sitemap.xml` lists every public artifact page (the same three conditions the page itself applies — published, project public, post not hidden), and the page carries its own words in `<noscript>` for anything that reads HTML without running it | `server/sitemap.ts`, `shared/path-artifacts.ts` (`injectPageMeta`) | `test/integration/sitemap.test.ts` (listed, then dropped the moment the page would 404), `test/unit/path-artifacts.test.ts` (the text, and its escaping), `e2e/growth-loop.spec.ts` |
| A stranger lands on `/a/:id` → **Explore this project and its path** or **Start your own path** on the same goal → signs up → onboarding lands them on that project, or straight into project create with the goal chosen | `client/src/pages/public-artifact.tsx` (both CTAs, `PENDING_PATH_KEY`), `client/src/App.tsx` (public route), `client/src/pages/landing.tsx` (`?signup=1`, sends `fromArtifact`), `server/attribution.ts` (credit by first landing page or `fromArtifact` → `creditArtifactSignup`), `client/src/pages/onboarding.tsx` + `shared/path-artifacts.ts` (`parsePendingPath`, `afterOnboardingPath` → `/projects/new/create`) | integration: `signups` counted both ways, `signupLandingPath` = `/a/:id`; unit: `afterOnboardingPath`; e2e: CTAs, signup and onboarding in the browser |
| **Project create on that goal, then its path**: the goal is preselected and kept (through a reload, and over an older draft) until the project exists; creating it instantiates the goal's path, clears the choice, and lands on the path's section with the first step up next | `client/src/pages/project-create.tsx` (`pendingPathGoal`, cleared in `createMutation.onSuccess`, `afterPendingCreatePath`), `POST /api/projects` (`instantiatePathTree`) | e2e: goal pressed after reload, `?section=ship_mvp`, choice cleared, "Product statement" next |
| **The way back**: the author is notified (`artifact_signup`); the newcomer writes their first step themselves (**Write it myself** → the step's answer, marked done — no Nova needed), and **Publish** beside it makes their own artifact, public and on the feed | `server/notifications.ts`, `shared/notifications.ts`, `client/src/components/section/next-step.tsx` (write form, `button-publish-finished-step` → `PublishArtifactDialog`) | integration + `e2e/growth-loop.spec.ts`: author's bell; the newcomer's whole run in the browser, their artifact readable logged out |

Safety: only the project's team can generate or publish; private projects can't publish, and making a project private (or a moderator hiding the feed post, or unpublishing) takes the page down. Artifacts list file paths and purposes, never file contents. Anonymous page views read path progress without syncing anything (`pathProgress`).
